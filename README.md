# Europe-to-Africa Remittance Visualization Analysis

This repository contains a data visualization analysis of remittance costs, channels, and uneven digital change across Europe-to-Africa corridors.

## Project focus

The analysis examines whether digital remittance channels are associated with lower costs, and how this pattern varies across corridors, destinations, and time.

## Data sources

- World Bank Remittance Prices Worldwide (RPW)
- World Bank / KNOMAD bilateral remittance matrix

## Visualizations

- Sankey diagram for corridor flow structure
- small multiples for remittance cost trends over time
- connected lollipop / dumbbell chart for bank vs digital channel comparison
